# Бизнес-план: AI-агент (голосовой) как SaaS для бизнеса в Узбекистане

## Идея

Универсальный голосовой AI-агент, который бизнес в Узбекистане может "нанять"
вместо (или в помощь) живому администратору/оператору:

- принимает входящие звонки и отвечает на вопросы;
- делает исходящие (в т.ч. холодные) звонки;
- записывает клиента на услугу/курс (booking) через календарь/CRM;
- умеет вести продающий диалог по скрипту с обработкой возражений.

Один и тот же "движок" настраивается под **профиль клиента-бизнеса**:

- 🎓 **Учебный центр / курсы** — консультирует по курсам, записывает на курс/пробный урок.
- 💇 **Салон красоты** — записывает на услугу к мастеру на конкретное время.
- 🛒 **Продающая компания** — холодные звонки, презентация продукта, закрытие на продажу/заявку.

## Продукт и модель монетизации

SaaS-подписка на "AI-администратора" с тремя готовыми пресетами (шаблонами
сценариев) + конструктор для кастомизации под конкретного клиента.

**Сегменты:**
- Учебные центры (курсы, репетиторские центры, IT-школы) — приём заявок + запись на пробный урок.
- Салоны красоты / барбершопы / клиники (стоматологии, косметология) — запись на приём.
- Отделы продаж (b2b/b2c) — обзвон базы, квалификация лида, назначение встречи.

**Тарифы (ориентир, требует калибровки на пилоте):**
- **Старт** — фиксированная плата + лимит минут разговора/звонков в месяц.
- **Бизнес** — больше минут + CRM-интеграция + кастомный скрипт.
- **Индивидуальный** — обучение сценария под конкретный бизнес, выделенный номер.

Монетизация: подписка + оплата за перерасход минут. Себестоимость минуты
разговора = STT + LLM + TTS + телефония (см. `architecture.md`, раздел
"Себестоимость"). На старте закладывать тариф клиенту с запасом ×3–5 к
себестоимости, уточнить точные цифры по итогам пилота.

## Go-to-market

1. Пилот на 2–3 знакомых бизнеса (по одному на каждый профиль), бесплатно или
   по себестоимости, в обмен на обратную связь и кейс.
2. Кейсы/демо-звонки как маркетинговый материал.
3. Продажи через Telegram/Instagram таргет на владельцев малого бизнеса в
   Ташкенте и других крупных городах.
4. Партнёрство с местными интеграторами Bitrix24/amoCRM как канал продаж
   (у них уже есть база клиентов малого/среднего бизнеса).

## Roadmap MVP (минимальный бюджет, 1–2 месяца)

**Неделя 1–2 — Фундамент**
- Виртуальный номер / SIP-транк (тестовый DID Узбекистана).
- Минимальный backend + телефонная платформа.
- STT/TTS pipeline (эхо-тест: сказал фразу — услышал синтез).
- Базовый диалог через LLM без function calling.

**Неделя 3–4 — Первый рабочий сценарий**
- Профиль "Салон красоты" (услуги + расписание + запись).
- Интеграция с Google Calendar.
- Обработка прерываний (barge-in), эскалация на человека.
- Внутреннее тестирование живыми звонками.

**Неделя 5–6 — Остальные профили**
- Профиль "Курсы" (консультация + запись на пробный урок).
- Профиль "Продажи/холодные звонки" (скрипт, возражения, передача тёплого лида).
- Логирование звонков + простой дашборд для владельца бизнеса.

**Неделя 7–8 — Пилот и запуск**
- Пилот с реальными компаниями по каждому профилю.
- Донастройка промптов/сценариев по реальным звонкам.
- Юридическая памятка готова (см. `compliance.md`).
- Тарифы, лендинг, старт продаж.

## Минимальная команда

- **Founder/PM** — сценарии, продажи, работа с пилотными клиентами.
- **Backend/AI-инженер** (может быть тот же founder) — весь технический пайплайн.
- Опционально парт-тайм/аутсорс: **носитель узбекского языка** — вычитка и
  тестирование UZ-сценариев (устная речь заметно отличается от письменной,
  критично для качества восприятия STT/TTS).

## Ключевые риски

- **Латентность** STT→LLM→TTS может ощущаться как неестественная пауза —
  нужен стриминг и короткие фразы-заполнители ("секунду, проверяю...").
- **Качество узбекской речи** (акценты, диалекты) — тестировать несколько
  STT-провайдеров уже в MVP, а не откладывать на потом.
- **Регуляторика по персональным данным** — см. `compliance.md`.
- **Спам-фильтры операторов** при холодных обзвонах — ограничивать частоту
  звонков с одного номера, ротация номеров.

См. также `architecture.md` (техническая реализация) и `compliance.md`
(юридические требования в Узбекистане).
